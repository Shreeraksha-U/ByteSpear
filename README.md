# ByteSpear (Blog-Website)

A static IT blog built with HTML5, CSS and vanilla JavaScript. 

## Project structure

```
.
├── index.html                 # Home page
├── pages/                     # All other pages
│   ├── programming.html
│   ├── cybersecurity.html
│   ├── cloud.html
│   ├── ai-ml.html
│   └── contact.html
├── assets/
│   ├── css/
│   │   ├── base.css           
│   │   ├── layout.css         
│   │   └── pages/             
│   │       ├── home.css
│   │       ├── category.css   # Shared by the 4 topic pages
│   │       └── contact.css
│   └── js/
│       ├── theme.js           # Light/dark theme 
│       └── search.js          # Live search filter
├── .editorconfig
├── .gitignore
└── README.md
```
